# Handoff to Cursor: pattern language repo

Paste everything below the line into Cursor, with `DESIGN.md` and `AGENTS.md` from this folder copied into the repo root (DESIGN.md goes to `docs/design/DESIGN.md`).

---

Goal: build the pattern language repo described in `docs/design/DESIGN.md`. It encodes a pattern language for buildings as JSON records, a Python checker over IFC models, Lean proofs of the language laws, an MCP server, and a Blender adapter. Read `AGENTS.md` and the whole design first.

Work rules:

1. Load pstack (`/pstack:poteto-mode`, then **architect**) before each unit. Name the data shape before code.
2. Build units U0 to U7 in order, one unit per draft pull request. Do not start a unit until the previous one's "done when" check passes. Torian merges.
3. Every pattern record holds number, name, scale, confidence, links and a source pointer. Never copy the book's problem or solution text, and never scrape patternlanguage.com. Summaries, forces and conditions are our own words. For the seed records, leave `summary` and `forces` as short drafts marked `"draft": true` for Torian to confirm against the book.
4. Use the standard terms in the design (IFC, BOT, CityJSON, BFO, and the book's own terms). Do not coin new user-facing terms. If a term seems missing, stop and list it in the PR body.
5. `topology.py` is the only module that imports IfcOpenShell. Only `adapters/blender` imports `bpy`. Condition checks are pure functions in a registry, not branches in the checker.
6. Fixtures are generated by `scripts/make_fixtures.py`, never downloaded or hand-edited. For each computed condition, one house that passes and one that fails.
7. The Lean catalog file is generated by `scripts/catalog_to_lean.py` and CI fails when it is stale. Lean follows spct-lean conventions: structures not global axioms, every field tagged [D], [S] or [P], and each [S] says what would make it false. No Mathlib.
8. Architecture views in docs are statecharts (mermaid `stateDiagram-v2`). Update the README nearest the code in every PR.
9. Never read or print `.env*` files. No Co-Authored-By trailer.

Done for the whole handoff: U7's recorded run, where an agent builds a small house in Blender by following the sequence for the twelve seed patterns, each step's report is logged under `runs/`, and the final step's report shows every computed pattern satisfied with no step that broke an earlier one.
